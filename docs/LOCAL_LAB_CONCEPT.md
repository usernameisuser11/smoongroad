# 수뭉로드 Local Lab — 최종 콘셉트

## 한 문장

**지역에는 해결할 문제가 있고, 대학에는 해결할 사람이 있습니다. 수뭉로드 Local Lab은 그 둘을 연결합니다.**

상명대학교와 종로구의 문제를 따로 보지 않고, 서로 겹치는 실제 문제를 질문형으로 공개한 뒤 학생의 전공 프로젝트, 기업·전문가 1:1 멘토링, 자원봉사 연계, 기관 현장실증으로 해결하는 지역문제 해결 플랫폼입니다.

## 문제를 보여주는 방식

딱딱한 행정 제목보다 관심을 끄는 질문형 제목을 우선 사용합니다.

- 상명대 학생과 종로구 주민이 같은 시간대 버스에서 불편을 겪는 이유는 뭘까?
- 상명대 학생들은 왜 바로 옆 지역상권을 잘 이용하지 않을까?
- 상명대 앞 언덕은 학생·주민·상인 모두에게 더 나은 길이 될 수 없을까?
- 키오스크 앞에서 주문을 포기하는 어르신을 줄일 수 있을까?
- 관광객은 많은데 왜 어떤 골목에는 사람이 머물지 않을까?

## 문제 등록 원칙

수뭉로드는 새로운 민원 접수창구를 만들지 않습니다.

1. 주민은 기존 지자체의 공식 건의·참여 채널을 그대로 이용합니다.
2. 서울시·종로구·상명대학교·복지기관·지역단체 등 Problem Owner가 해결 필요성을 검토합니다.
3. 학생 프로젝트로 해결 가능한 문제만 Local Lab에 공개합니다.
4. 주민은 수뭉로드에서 공감, 현장 경험 공유, 프로토타입 테스트, 결과 평가로 참여합니다.

이 구조로 행정 민원과 학생 프로젝트의 역할을 분리해 불필요한 중간 단계를 줄입니다.

## 핵심 흐름

```text
기관이 실제 문제 검증·등록
→ AI가 문제 구조화 및 필요한 역량 분석
→ 상명대학교 관련 전공·학생 역할 추천
→ 다전공 프로젝트 팀 구성
→ 기업·전문가 1:1 멘토링
→ 자원봉사센터·현장기관 연계
→ MVP 제작
→ 주민·기관 현장 테스트
→ Before / After 성과 기록
→ 수료 기록·포트폴리오
→ 우수 결과 실제 도입 검토
```

## 참여 주체별 역할

### 서울시·종로구

- 검증된 지역문제 제공
- 공공데이터·현장기관 연결
- 프로토타입 현장 테스트 지원
- 우수 결과의 실제 도입 가능성 검토

### 상명대학교

- 전공·교과·비교과와 프로젝트 연결
- 학생팀 구성
- 교수·학교 부서 협업
- 프로젝트 수료 및 성과 기록

### 자원봉사센터

- 사회참여 프로젝트의 봉사활동 연계 가능성 검토
- 현장 봉사기관 연결
- 활동 기록 지원

**주의:** 공식 봉사시간·확인서는 자원봉사센터와의 사전 협의 및 인정 요건 충족이 전제됩니다.

### 기업·전문가

- 학생 역할에 맞는 1:1 실무 멘토링
- API·데이터·장비 등 프로젝트 자원 지원
- 서비스 기획·기술·디자인·정책 피드백
- ESG/CSR 및 대학 인재 발굴과의 연계 가능성

## 학교와 지역사회를 동시에 해결하는 기준

Local Lab은 아래처럼 두 영역이 겹치는 문제를 우선합니다.

| 질문 | 학교 측 문제 | 지역사회 측 문제 |
| --- | --- | --- |
| 같은 시간대 버스 불편을 어떻게 줄일까? | 학생 통학 | 주민 생활교통 |
| 학생들은 왜 인근 상권을 잘 이용하지 않을까? | 학생 생활권 | 골목상권 유입 |
| 상명대 앞 언덕을 더 나은 길로 만들 수 있을까? | 통학·보행 | 주민 이동·상권 접근 |
| 대학의 프로젝트가 지역 현장에서 쓰일 수 있을까? | 실무 경험 부족 | 문제 해결 인력 부족 |

## 학생에게 제공되는 가치

- 실제 Client가 있는 프로젝트 경험
- 자신의 전공을 활용한 지역사회 문제 해결
- 기업·전문가 1:1 멘토링
- 프로젝트 수료 기록
- 결과물·Before/After·Client 피드백을 포함한 포트폴리오
- 협약된 프로젝트의 경우 자원봉사 활동 연계 가능성

## 핵심 차별점

수뭉로드 Local Lab은 지역문제 게시판이 아닙니다.

**검증된 지역문제 → 대학 전공 프로젝트 → 실무 멘토링 → 현장 실증 → 성과 기록**을 한 흐름으로 연결하는 것이 핵심입니다.
